# Desenvolviment_R
Desenvolviment_R é um diário pessoal de metas, construído com a premissa de que o processo importa tanto quanto o resultado.  Registrar a trajetória — as tentativas, os avanços, os recuos, os aprendizados — de forma que, ao alcançar uma meta, o usuário possa olhar para trás e ver o quanto cresceu no caminho.
